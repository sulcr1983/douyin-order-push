# 📦 抖店订单自动化流转中心 (V3.0 终极版)

本系统实现了从“抖店导出”到“企业微信智能表格”的全链路、无感化数据增量同步。彻底告别手动改名、告别人工查重、告别繁琐搬运。
可以自己修改兼容不同的电商平台下载的数据，通过python清洗数据导入到自己的企业微信-飞书-钉钉或者各种rep系统去。

## ✨ V3.0 核心突破 (What's New)

- **🤖 智能雷达扫描 (V3 新增)**：彻底废弃固定文件名限制。系统会自动扫描指定文件夹，精准锁定时间戳最新的 CSV 文件进行读取，实现“即下即跑”的 RPA 级体验。
- **🧠 本地增量大脑**：内置轻量级 SQLite 数据库（`orders_storage.db`）。自动对比历史订单，仅推送“新增”或“状态变更”的订单，拒绝企微表格刷屏，保护 API 配额。
- **🧹 工业级清洗引擎**：强力剥离抖店原始数据中的 `\t`、空格、引号等不可见字符，确保生成的订单号、手机号 100% 为纯净数字格式。
- **🛡️ 智能容错机制**：自适应读取 `utf-8-sig` 与 `gbk` 编码，自带网络发送 3 次重试机制及 0.5 秒频率保护。

## 🛠️ 环境与初始化

### 1. 运行环境要求

- Python 3.10 或更高版本
- 依赖库安装：在终端执行 `pip install -r requirements.txt`

### 2. 核心配置文件 (.env)

首次运行前，必须在脚本同级目录创建一个名为 `.env` 的文件，并填入以下两项核心参数：

```env
# 1. 企业微信智能表格【自动化流程 -> 接收 Webhook】的地址
WECOM_WEBHOOK_URL=[https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxx](https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxx)

# 2. 你的抖店订单统一存放路径 (V3 核心配置)
# 注意：Windows 系统请务必将路径中的反斜杠 \ 改为正斜杠 /
CSV_FOLDER_PATH=C:/Users/Administrator/Desktop/抖店订单
```
